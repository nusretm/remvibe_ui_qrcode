# RemVibe UI QR

Reusable Flutter QR-code display and mobile scanning widgets.

> Project initialization in progress. No Flutter package code or platform validation has been completed yet.

- Package: `remvibe_ui_qrcode`
- QR display: Windows, Linux, macOS (also usable on Android/iOS)
- QR scanner: Android and iOS only
- Web: outside the supported scope

Development rules and integration documentation will be added on the feature branch.
